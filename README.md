# TextEdit

โปรแกรม Text Editor แบบบรรทัดคำสั่ง เขียนด้วยภาษา C ใช้ **Stack แบบ Linked List** เก็บประวัติเพื่อทำ Undo

## ฟีเจอร์

- **Add text**: ต่อข้อความใหม่ท้ายข้อความเดิม
- **Edit last text**: แทนที่เฉพาะข้อความชุดล่าสุดที่เพิ่มเข้าไป
- **Undo**: ย้อนกลับไปสถานะก่อนหน้า (ย้อนได้ต่อเนื่องจนหมดประวัติ)
- **Show**: แสดงข้อความปัจจุบัน

## เมนู

```
===== Text Editor =====
1. Add text
2. Edit last text
3. Undo
4. Show
0. Exit
```

## ตัวอย่างการใช้งาน

| ลำดับ | เมนู | ข้อความที่พิมพ์ | ข้อความปัจจุบัน |
|-------|------|-----------------|------------------|
| 1 | Add | `Hello` | `Hello` |
| 2 | Add | ` World` | `Hello World` |
| 3 | Edit | `There` | `HelloThere` |
| 4 | Undo | – | `Hello World` |
| 5 | Undo | – | `Hello` |
| 6 | Undo | – | `Nothing to undo.` |

## โครงสร้างโค้ด

| ส่วน | หน้าที่ |
|------|---------|
| `Node` / `Stack` | Linked List ที่ใช้เป็น Stack แต่ละ Node เก็บข้อความและ `lastStart` ของสถานะนั้น |
| `push` / `pop` | เพิ่ม / ดึงสถานะบนสุดของ Stack |
| `addText` | เก็บสถานะลง Stack แล้วต่อข้อความท้ายสุด |
| `editText` | เก็บสถานะลง Stack ตัดชุดล่าสุดทิ้ง แล้วต่อข้อความใหม่แทน |
| `undo` | ดึงสถานะล่าสุดจาก Stack กลับมาเป็นข้อความปัจจุบัน |
| `lastStart` | ตำแหน่งเริ่มของข้อความชุดล่าสุด ใช้ตอน Edit |

## ข้อจำกัด

- ข้อความยาวได้ไม่เกิน 255 ตัวอักษร (`MAX_TEXT = 256`) ถ้าเกินจะแจ้ง `Text too long!` และไม่ทำรายการนั้น
- ไม่มี Redo
- การพิมพ์ตัวอักษรที่ไม่ใช่ตัวเลขในเมนูจะทำให้โปรแกรมจบการทำงาน
